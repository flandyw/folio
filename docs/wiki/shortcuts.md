# Gestures and shortcuts

[Wiki home](README.md) · [Getting started](getting-started.md) · [Writing](writing.md)

Folio includes an in-app **Gestures and shortcuts** guide; open it from the editor command palette or **Settings → Stylus & touch**. Single-letter tool shortcuts can be customised or disabled in **Settings → Writing**; they work on the canvas whenever text entry and panels are closed.

## Keyboard

| Keys | Action |
| --- | --- |
| `Ctrl + K` | Open the command palette |
| `P` / `E` / `H` / `L` / `V` / `T` | Default pen, eraser, highlighter, lasso, hand, and text tools |
| Hold `Space` | Temporarily switch to the hand tool |
| `Ctrl + C` / `X` / `V` | Copy, cut, or paste selection |
| `Ctrl + A` / `D`; `Delete` | Select all; duplicate selection; delete selection |
| `Ctrl + Z`; `Ctrl + Shift + Z` or `Ctrl + Y` | Undo; redo |
| `Ctrl + Tab` / `Ctrl + Shift + Tab` | Next / previous notebook |
| `Ctrl + \` | Open or close split view |
| `Page Up` / `Page Down`; `Ctrl + Home` / `End` | Previous / next page; first / last page |
| `Ctrl + N`; `Ctrl + Enter`; `Ctrl + Shift + D` | New notebook; insert page; duplicate page |
| `Ctrl + F` / `G`; `Ctrl + 0` | Find in document / go to page; reset zoom |
| `Alt + Left` / `Right` | Back / forward in navigation history |
| `Alt + Down` / `Up` | Next / previous writing line when writing follow is active |
| `Alt + Backspace`; `Escape` | Return to previous writing view; cancel crop or clear selection |

`Ctrl + Enter` commits the active text draft when editing text. Available shortcuts depend on focus and the active screen; check the in-app guide for the current context.

## Touch and stylus

- **Navigate:** Pinch to zoom and drag with the hand tool to pan. In split view, finger navigation works in either pane without moving editor focus.
- **Ruler:** Slide with one finger; rotate with two.
- **Undo/redo taps:** When enabled, a two-finger tap undoes and a three-finger tap redoes (toolbar buttons remain available).
- **Stylus button:** Configure palm rejection and pencil double-tap shortcuts in **Settings → Stylus & touch**. Folio's pencil double-tap action supports OnePlus and OPPO styluses; other pens use their system shortcut. See [Palm rejection](../palm-rejection.md) for details and device checks.
