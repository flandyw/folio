# Gestures and shortcuts

[Wiki home](README.md) · [Getting started](getting-started.md) · [Writing](writing.md)

Folio also has an in-app **Gestures and shortcuts** guide. Open it from the editor's command palette or from Settings → Stylus & touch. Tool letter shortcuts can be turned off or changed in Settings → Writing. They work on the canvas, outside text entry and panels.

## Keyboard

| Keys | Action |
| --- | --- |
| Ctrl + K | Find an action in the command palette |
| P / E / H / L / V / T | Default pen, eraser, highlighter, lasso, hand and text tools |
| Hold Space | Temporarily use the hand |
| Ctrl + C / X / V | Copy, cut or paste selection |
| Ctrl + A / D; Delete | Select all, duplicate selection; delete selection |
| Ctrl + Z; Ctrl + Shift + Z or Ctrl + Y | Undo; redo |
| Ctrl + Tab / Ctrl + Shift + Tab | Next / previous notebook |
| Ctrl + \\ | Open or close split view |
| Page Up / Page Down; Ctrl + Home / End | Previous / next page; first / last page |
| Ctrl + N; Ctrl + Enter; Ctrl + Shift + D | New notebook; insert page; duplicate page |
| Ctrl + F / G; Ctrl + 0 | Find in document / go to page; reset zoom |
| Alt + Left / Right | Back / forward in navigation history |
| Alt + Down / Up | Next / previous writing line when writing follow is active |
| Alt + Backspace; Escape | Return to previous writing view; cancel crop or clear selection |

Ctrl + Enter applies a text draft when editing text. Keyboard actions can depend on focus and the active screen; check the in-app guide for the current context.

## Touch and stylus

Pinch to zoom and use the hand tool to pan. In split view, fingers navigate either pane without switching the editor focus. On the ruler, one finger slides it and two fingers rotate it. If enabled, a two-finger tap undoes and a three-finger tap redoes; toolbar buttons remain available.

Settings → Stylus & touch has palm-rejection and pencil-shortcut controls. Folio's pencil double-tap action supports OnePlus and OPPO pencils; other pens use their system shortcut. See [palm rejection](../palm-rejection.md) for details and device checks.
