# Getting started

[Wiki home](README.md) · [Notebooks](notebooks.md) · [Writing](writing.md) · [Backups](data-and-settings.md)

Folio works on Android 8.0 and newer. The core notebook works offline. Screen layouts adapt to the available space, so navigation and labels may appear in a menu or on a rail.

## Create or import

1. Open **Library** and choose **Create or import**.
2. Choose **New notebook**, **Quick note** or **Infinite canvas**. You can also create a folder from this menu.
3. To annotate an existing PDF, choose **Import PDF document** and select the file. To open a portable notebook, choose **Import Folio backup** and select its `.folio` file.
4. Open the notebook from the Library. Choose a tool in the editor toolbar and start writing, or use the hand tool to navigate.

A PDF imported from **Files** is copied into Folio; editing the notebook does not change the original file. [Notebooks and the library](notebooks.md) covers pages, folders, search and Trash.

## Make your first edit

- Select pen or highlighter and write on the page. Choose the tool's options to adjust its appearance.
- Use the eraser to remove ink, or lasso to select content for moving and other actions. Undo and redo are available in the toolbar or its overflow menu.
- Choose text and tap the page to type. For a sticky note, select the sticky tool and tap to add one or drag to size it.
- Use the page browser to move between pages. Pinch to zoom; the hand tool pans the view. On an infinite canvas you can pan and write freely.

See [writing and editing](writing.md) for shape assist, layers, handwriting recognition and writing follow. [Gestures and shortcuts](shortcuts.md) lists the keyboard controls and where to find the in-app guide.

## Export and protect your work

For a document to read or share, use the notebook's export options to save PDF or an image. To retain editable pages and undo history for a single notebook, choose **Save as Folio backup**. To save the included library, open **Settings → Backup & restore → Save library backup**. These options serve different purposes; see [data and settings](data-and-settings.md) before moving or deleting data.

## Explore other destinations

- **VCAA** finds exam papers to import. **Mistakes**, **Study**, **Progress** and **Planner** support revision, timing and planning; account-connected features use Focal. See [study and exams](study.md).
- **Music** is a separate score collection. Import sheet-music PDFs there and annotate them in the reader. See [music](music.md).
- **Settings** controls appearance, writing, stylus and touch, backups and accounts. Search settings if you cannot find a control.
